## 三、密码加密（BCrypt）

密码绝不能明文存库。使用 Spring Security 提供的 `BCryptPasswordEncoder`（只引入 crypto 模块即可，无需完整 Spring Security）。

> 依赖库速览：`spring-security-crypto` 是 Spring Security 框架里**只做加密的轻量模块**（不包含登录拦截那套重量级机制）。它提供 `BCryptPasswordEncoder`——一种**单向不可逆 + 自动加盐**的密码哈希算法：即使两个用户设了相同密码，加密结果也完全不同；且哈希不可反解，数据库泄露也无法还原明文。注册时 `encode()` 加密存储，登录时 `matches()` 比对。

依赖：

```xml
<dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-crypto</artifactId>
</dependency>
```

配置 Bean：

```java
package com.mall.mall.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;

@Configuration
public class SecurityConfig {

    @Bean
    public BCryptPasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
```

用法：

```java
// 注册时：把明文加密后存库
String encoded = passwordEncoder.encode("123456");   // 结果如 $2a$10$xxx...

// 登录时：校验用户输入的密码是否匹配
boolean ok = passwordEncoder.matches("123456", encoded);
```

> BCrypt 是「单向」加密，无法反解出明文，只能通过 `matches` 比对。这就是为什么登录是「比对」而不是「解密」。

### 5. Service

```java
package com.mall.mall.service;

import com.baomidou.mybatisplus.core.conditions.query.QueryWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.baomidou.mybatisplus.extension.service.impl.ServiceImpl;
import com.mall.mall.common.BusinessException;
import com.mall.mall.dto.MerchantLoginDTO;
import com.mall.mall.dto.MerchantRegisterDTO;
import com.mall.mall.entity.Merchant;
import com.mall.mall.mapper.MerchantMapper;
import com.mall.mall.vo.MerchantVO;
import org.springframework.beans.BeanUtils;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.stereotype.Service;

@Service
public class MerchantService extends ServiceImpl<MerchantMapper, Merchant> {

    private final BCryptPasswordEncoder passwordEncoder;

    public MerchantService(BCryptPasswordEncoder passwordEncoder) {
        this.passwordEncoder = passwordEncoder;
    }

    // 注册
    public void register(MerchantRegisterDTO dto) {
        // 1. 账号唯一性校验
        long count = this.count(new QueryWrapper<Merchant>().eq("username", dto.getUsername()));
        if (count > 0) {
            throw new BusinessException("账号已存在");
        }
        // 2. 组装实体，密码加密
        Merchant merchant = new Merchant();
        BeanUtils.copyProperties(dto, merchant);
        merchant.setPassword(passwordEncoder.encode(dto.getPassword()));
        merchant.setStatus(1);
        // 3. 入库
        this.save(merchant);
    }

    // 登录
    public MerchantVO login(MerchantLoginDTO dto) {
        Merchant merchant = this.getOne(
                new QueryWrapper<Merchant>().eq("username", dto.getUsername()));
        if (merchant == null || !passwordEncoder.matches(dto.getPassword(), merchant.getPassword())) {
            throw new BusinessException("账号或密码错误");
        }
        if (merchant.getStatus() == 0) {
            throw new BusinessException("账号已被禁用");
        }
        MerchantVO vo = new MerchantVO();
        BeanUtils.copyProperties(merchant, vo);
        return vo;
    }

    // 查单个
    public MerchantVO getMerchant(Long id) {
        Merchant merchant = this.getById(id);
        if (merchant == null) {
            throw new BusinessException("店家不存在");
        }
        MerchantVO vo = new MerchantVO();
        BeanUtils.copyProperties(merchant, vo);
        return vo;
    }

    // 分页查询
    public Page<MerchantVO> page(int pageNum, int pageSize, String keyword) {
        Page<Merchant> page = new Page<>(pageNum, pageSize);
        QueryWrapper<Merchant> wrapper = new QueryWrapper<>();
        if (keyword != null && !keyword.isBlank()) {
            wrapper.like("shop_name", keyword).or().like("username", keyword);
        }
        wrapper.orderByDesc("id");
        this.page(page, wrapper);

        // 转成 VO（隐藏密码）
        Page<MerchantVO> voPage = new Page<>(pageNum, pageSize, page.getTotal());
        voPage.setRecords(page.getRecords().stream().map(m -> {
            MerchantVO vo = new MerchantVO();
            BeanUtils.copyProperties(m, vo);
            return vo;
        }).toList());
        return voPage;
    }
}
```

> `BeanUtils.copyProperties` 用于同名字段间的对象拷贝（Entity ↔ DTO/VO），省去手写 getter/setter。

### 6. Controller

```java
package com.mall.mall.controller;

import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.mall.mall.common.Result;
import com.mall.mall.dto.MerchantLoginDTO;
import com.mall.mall.dto.MerchantRegisterDTO;
import com.mall.mall.service.MerchantService;
import com.mall.mall.vo.MerchantVO;
import jakarta.validation.Valid;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/merchants")
public class MerchantController {

    private final MerchantService merchantService;

    public MerchantController(MerchantService merchantService) {
        this.merchantService = merchantService;
    }

    @PostMapping("/register")
    public Result<Void> register(@Valid @RequestBody MerchantRegisterDTO dto) {
        merchantService.register(dto);
        return Result.success();
    }

    @PostMapping("/login")
    public Result<MerchantVO> login(@Valid @RequestBody MerchantLoginDTO dto) {
        return Result.success(merchantService.login(dto));
    }

    @GetMapping("/{id}")
    public Result<MerchantVO> get(@PathVariable Long id) {
        return Result.success(merchantService.getMerchant(id));
    }

    @GetMapping("/page")
    public Result<Page<MerchantVO>> page(
            @RequestParam(defaultValue = "1") int pageNum,
            @RequestParam(defaultValue = "10") int pageSize,
            @RequestParam(required = false) String keyword) {
        return Result.success(merchantService.page(pageNum, pageSize, keyword));
    }
}
```

## 五、开启分页插件

> ⚠️ 前提：**MyBatis-Plus 3.5.9+ 已把分页插件拆成独立模块**，只引 starter 不够，必须先加依赖（版本与 starter 一致）。

```xml
<!-- 分页插件 PaginationInnerInterceptor 所在模块（3.5.9+ 必须单独引入） -->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-jsqlparser</artifactId>
    <version>3.5.15</version>
</dependency>
```

> 不加此依赖会出现「无法解析符号 `PaginationInnerInterceptor`」——因为它所在的 jar 根本没下载。

MyBatis-Plus 分页需要手动注册分页插件，否则 `page()` 不会真正分页：

```java
package com.mall.mall.config;

import com.baomidou.mybatisplus.annotation.DbType;
import com.baomidou.mybatisplus.extension.plugins.MybatisPlusInterceptor;
import com.baomidou.mybatisplus.extension.plugins.inner.PaginationInnerInterceptor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class MybatisPlusConfig {

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}
```

## 六、验收清单

- [ ] 注册后，数据库 `password` 字段是 BCrypt 密文（以 `$2a$` 开头）
- [ ] 重复账号注册返回「账号已存在」
- [ ] 密码错误登录返回「账号或密码错误」
- [ ] 查询接口返回的 VO **不含 password 字段**
- [ ] 分页查询返回 `records`、`total`、`current`、`size` 等正确信息
- [ ] 传非法参数（如空账号）返回统一校验错误

## 七、常见坑

| 问题 | 原因与解决 |
| --- | --- |
| 分页不生效（返回全部） | 没注册 `MybatisPlusInterceptor` 分页插件 |
| `BeanUtils.copyProperties` 拷贝不到值 | 源/目标字段名或类型不一致 |
| BCrypt 每次加密结果不同 | 正常现象（加盐），用 `matches` 比对即可 |
| `@Valid` 报 500 而非统一错误 | 校验异常未被全局异常处理器捕获，需额外处理 `MethodArgumentNotValidException`（阶段八补充） |
