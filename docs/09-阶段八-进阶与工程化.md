## 二、JWT 登录鉴权

前面阶段登录后只是返回了店家信息，但**接口没有任何保护**——任何人都能调用修改接口。现在用 JWT 补上鉴权。

### 1. 什么是 JWT

JWT（JSON Web Token）是一种无状态令牌。登录成功后服务端签发一个 token 给前端，前端每次请求带上它，服务端校验通过才放行。

```
登录成功 → 签发 token → 前端存 token → 后续请求携带 token → 服务端校验 → 放行
```

> 前端视角：就像登录后 `localStorage` 存 token，之后每个请求 `Authorization: Bearer xxx`，服务端据此判断「你是谁」。

### 2. 依赖

> 依赖库速览：**JJWT**（Java JWT，`io.jsonwebtoken`）是 Java 最流行的 JWT 生成/解析库，按「接口与实现分离」拆成 3 个 jar，需要全部引入：
> - `jjwt-api`：编译期要用的 API 与注解
> - `jjwt-impl`：真正的实现代码（运行期才需要，故 `scope=runtime`）
> - `jjwt-jackson`：让 JWT 支持用 Jackson 序列化/反序列化 JSON（同样是运行期依赖）

```xml
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-api</artifactId>
    <version>0.12.5</version>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-impl</artifactId>
    <version>0.12.5</version>
    <scope>runtime</scope>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-jackson</artifactId>
    <version>0.12.5</version>
    <scope>runtime</scope>
</dependency>
```

### 3. JWT 工具类

```java
@Component
public class JwtUtil {

    // 生产环境应从配置读取，且要足够长
    private final String secret = "your-secret-key-change-me-please-32chars";
    private final long expireSeconds = 7 * 24 * 3600;   // 7 天

    public String generate(Long merchantId, String username) {
        return Jwts.builder()
                .subject(username)
                .claim("merchantId", merchantId)
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + expireSeconds * 1000))
                .signWith(Keys.hmacShaKeyFor(secret.getBytes()))
                .compact();
    }

    public Long parseMerchantId(String token) {
        Claims claims = Jwts.parser()
                .verifyWith(Keys.hmacShaKeyFor(secret.getBytes()))
                .build()
                .parseSignedClaims(token)
                .getPayload();
        return claims.get("merchantId", Long.class);
    }
}
```

### 4. 登录接口签发 token

```java
public String login(MerchantLoginDTO dto) {
    Merchant merchant = this.getOne(
            new QueryWrapper<Merchant>().eq("username", dto.getUsername()));
    if (merchant == null || !passwordEncoder.matches(dto.getPassword(), merchant.getPassword())) {
        throw new BusinessException("账号或密码错误");
    }
    return jwtUtil.generate(merchant.getId(), merchant.getUsername());   // 返回 token

```

### 5. 拦截器校验 token

```java
@Component
public class AuthInterceptor implements HandlerInterceptor {

    private final JwtUtil jwtUtil;

    public AuthInterceptor(JwtUtil jwtUtil) {
        this.jwtUtil = jwtUtil;
    }

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        // 放行登录/注册等白名单接口
        String token = request.getHeader("Authorization");
        if (token != null && token.startsWith("Bearer ")) {
            token = token.substring(7);
            try {
                Long merchantId = jwtUtil.parseMerchantId(token);
                request.setAttribute("merchantId", merchantId);   // 传给后续逻辑
                return true;
            } catch (Exception e) {
                // token 无效
            }
        }
        response.setStatus(401);
        return false;
    }
}
```

注册拦截器并配置白名单：

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    private final AuthInterceptor authInterceptor;

    public WebConfig(AuthInterceptor authInterceptor) {
        this.authInterceptor = authInterceptor;
    }

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(authInterceptor)
                .addPathPatterns("/api/**")
                .excludePathPatterns(
                        "/api/merchants/register",
                        "/api/merchants/login"
                );
    }
}
```

## 三、参数校验异常统一处理（补坑）

阶段四提到 `@Valid` 校验失败会抛 `MethodArgumentNotValidException`，需要补上全局处理：

```java
@ExceptionHandler(MethodArgumentNotValidException.class)
public Result<Void> handleValidException(MethodArgumentNotValidException e) {
    String message = e.getBindingResult().getFieldErrors().stream()
            .map(FieldError::getDefaultMessage)
            .findFirst()
            .orElse("参数错误");
    return Result.fail(400, message);
}
```

> 已提前落地：这一条在补阶段七测试时就已经实现进 `GlobalExceptionHandler`（对应测试清单里的 G-2）。效果是参数校验失败返回 `code=400` + 第一个字段的提示语（如「账号不能为空」），不再是 `code=500`「系统内部错误」。本节可直接跳过，回头对照代码理解即可。

## 四、Redis 缓存

商品详情是典型的热点数据，读多写少，适合缓存。

### 1. 依赖与配置

> 依赖库速览：`spring-boot-starter-data-redis` 是 Spring 官方对 **Redis**（一款高性能内存键值数据库，常做缓存）的封装启动器。它自动帮你配置好连接工厂，并提供两个开箱即用的模板对象：`StringRedisTemplate`（字符串操作）和 `RedisTemplate`（任意对象，配合 JSON 序列化）。

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
```

### 2. 缓存模式（Cache-Aside）

```java
public ProductVO getProductWithCache(Long id) {
    String key = "product:" + id;
    // 1. 先查缓存
    String json = redisTemplate.opsForValue().get(key);
    if (json != null) {
        return objectMapper.readValue(json, ProductVO.class);
    }
    // 2. 缓存未命中，查数据库
    Product p = this.getById(id);
    if (p == null) {
        throw new BusinessException("商品不存在");
    }
    ProductVO vo = toVO(p);
    // 3. 写入缓存
    redisTemplate.opsForValue().set(key, objectMapper.writeValueAsString(vo), Duration.ofMinutes(30));
    return vo;
}
```

**更新商品时要删除缓存**，避免脏数据：

```java
public void updateProduct(Long id, ProductCreateDTO dto) {
    // ...更新逻辑
    redisTemplate.delete("product:" + id);   // 删除缓存，下次读取时重建
}
```

> 缓存三大问题（面试常考）：**缓存穿透**（查不存在的数据，用空值/布隆过滤器）、**缓存击穿**（热点 key 过期，用互斥锁）、**缓存雪崩**（大量 key 同时过期，用随机过期时间）。

## 五、Swagger 接口文档

> 依赖库速览：`springdoc-openapi-starter-webmvc-ui` 是 **SpringDoc** 库——它把 OpenAPI 3 规范（Swagger 的现代版本）自动集成进 Spring Boot：启动后扫描所有 `@RestController`，结合 `@Tag`/`@Operation` 等注解自动生成接口文档，并自带一个可视化调试页面 Swagger UI（访问 `/swagger-ui.html` 即可），相当于给后端接口免费送了个 Postman 风格的在线调试面板。

依赖：

```xml
<dependency>
    <groupId>org.springdoc</groupId>
    <artifactId>springdoc-openapi-starter-webmvc-ui</artifactId>
    <version>2.5.0</version>
</dependency>
```

给接口加注解，自动生成文档：

```java
@Tag(name = "商品管理")
@RestController
@RequestMapping("/api/products")
public class ProductController {

    @Operation(summary = "查询商品详情")
    @GetMapping("/{id}")
    public Result<ProductVO> get(@PathVariable Long id) { ... }
}
```

启动后访问 `http://localhost:8080/swagger-ui.html` 即可看到可交互的接口文档。
