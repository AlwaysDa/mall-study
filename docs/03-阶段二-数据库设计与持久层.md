# 03 · 阶段二：数据库与持久层

> 目标：学会用 MySQL 建库建表，并引入 MyBatis-Plus，把阶段一的内存 CRUD 改造成「真正的数据库 CRUD」。  
> 验收标准：重启服务后数据依然存在（已持久化到 MySQL），能在数据库客户端里看到数据。

## 一、本阶段要解决的问题

阶段一的数据存在内存里，重启就没了。真实后端必须把数据存到数据库。本阶段引入两个东西：

1. **MySQL**：数据真正存放的地方。
2. **MyBatis-Plus**：Java 与数据库之间的「翻译官」（ORM 框架），让你用 Java 对象操作数据库，少写 SQL。

> 前端视角：MyBatis-Plus 就像前端的 ORM（比如 Prisma / TypeORM），用对象代替手写 SQL，但保留了手写 SQL 的能力。

## 二、MySQL 基础速览

### 1. 建库

```sql
CREATE DATABASE mall DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

> `utf8mb4` 是能存 emoji 的完整 UTF-8，**建库建表一律用 utf8mb4**。

### 2. 建表（本阶段先建一张商品表）

```sql
USE mall;

CREATE TABLE product (
    id          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    name        VARCHAR(100) NOT NULL                COMMENT '商品名',
    price       DECIMAL(10,2) NOT NULL               COMMENT '价格',
    stock       INT          NOT NULL DEFAULT 0      COMMENT '库存',
    create_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品表';
```

**要点：**

| 要点                                  | 说明                             |
| ----------------------------------- | ------------------------------ |
| 主键 `BIGINT AUTO_INCREMENT`          | 自增主键，用 `Long` 类型对应             |
| 金额用 `DECIMAL`                       | **金额绝不能用 float/double**，会有精度丢失 |
| `ENGINE=InnoDB`                     | 支持事务（阶段六下单会用到）                 |
| 每张表都加 `create_time` / `update_time` | 好习惯，方便排查与审计                    |

### 3. 常用 SQL 速记

```sql
INSERT INTO product(name, price, stock) VALUES ('手机', 3999.00, 10);   -- 增
SELECT * FROM product WHERE id = 1;                                     -- 查单个
SELECT * FROM product WHERE name LIKE '%手机%';                          -- 模糊查
UPDATE product SET stock = 8 WHERE id = 1;                              -- 改
DELETE FROM product WHERE id = 1;                                       -- 删
```

> 建议：先在 DBeaver / IDEA 里手动执行几遍这些 SQL，熟悉了再交给框架。

## 三、引入 MyBatis-Plus

### 1. 加依赖（pom.xml）

这里要加**两个依赖库**，它们分工不同：

| 依赖库 | 是什么 | 负责什么 |
| --- | --- | --- |
| `mybatis-plus-spring-boot4-starter` | **MyBatis-Plus**（`com.baomidou` 出品，国内主流 MyBatis 增强框架）为 Spring Boot 4 提供的启动器 | 让 Mapper 接口继承 `BaseMapper` 就自动拥有增删改查方法，少写大量重复 SQL |
| `mysql-connector-j` | **MySQL 官方**提供的 Java 连接驱动（JDBC Driver） | 负责 Java 程序与 MySQL 之间的底层通信——没有它，程序连不上数据库 |

> 类比前端：`mybatis-plus` 约等于数据库层的 TypeORM / Prisma；`mysql-connector-j` 则像各数据库的官方 driver（如 pg / mysql2），是「连接数据库」本身就需要的那一层。

```xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot4-starter</artifactId>
    <version>3.5.15</version>
</dependency>
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

> 注意：Spring Boot 4 必须用 `mybatis-plus-spring-boot4-starter`（最低 3.5.9，推荐 3.5.15+）。不要用老的 `mybatis-plus-boot-starter`，也不要混用 boot3 的 starter，否则启动会直接报版本不兼容。

### 2. 配置数据源（application.yml）

```yaml
spring:
  datasource:
    # 整条 URL 用双引号包裹：避免 & 被某些编辑器/终端自动转义成 \& 导致 characterEncoding 值变成 "utf8\"
    url: "jdbc:mysql://localhost:3306/mall?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai"
    username: root
    password: 你的密码
    driver-class-name: com.mysql.cj.jdbc.Driver
```

## 四、改造：从内存 CRUD 到数据库 CRUD

### 1. 实体类加注解（Entity）

```java
package com.mall.mall.entity;

import com.baomidou.mybatisplus.annotation.*;
import lombok.Data;

import java.time.LocalDateTime;

@Data
@TableName("product")                  // 对应哪张表
public class Product {

    @TableId(type = IdType.AUTO)        // 主键自增
    private Long id;

    private String name;

    private Double price;               // 生产环境建议用 BigDecimal，学习期可先用 Double

    private Integer stock;

    @TableField(fill = FieldFill.INSERT)          // 插入时自动填充
    private LocalDateTime createTime;

    @TableField(fill = FieldFill.INSERT_UPDATE)   // 插入和更新时自动填充
    private LocalDateTime updateTime;
}
```

**注解速记：**

| 注解                             | 作用               |
| ------------------------------ | ---------------- |
| `@TableName`                   | 实体类 ↔ 表名映射       |
| `@TableId(type = IdType.AUTO)` | 标记主键并指定自增策略      |
| `@TableField(fill = ...)`      | 字段自动填充（配合下面的处理器） |

### 2. Mapper 接口（数据访问层）

```java
package com.mall.mall.mapper;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import com.mall.mall.entity.Product;
import org.apache.ibatis.annotations.Mapper;

@Mapper
public interface ProductMapper extends BaseMapper<Product> {
    // 继承 BaseMapper 后，单表 CRUD 全都自动拥有，无需写任何方法
}
```

> `BaseMapper<Product>` 已经内置了 `insert`、`selectById`、`selectList`、`updateById`、`deleteById` 等方法。单表操作基本不用写 SQL。

### 3. Service 层改造

```java
package com.mall.mall.service;

import com.baomidou.mybatisplus.extension.service.impl.ServiceImpl;
import com.mall.mall.entity.Product;
import com.mall.mall.mapper.ProductMapper;
import org.springframework.stereotype.Service;

@Service
public class ProductService extends ServiceImpl<ProductMapper, Product> {
    // 继承 ServiceImpl 后，直接拥有 list/getById/save/updateById/removeById 等方法
}
```

改造后，阶段一的 Controller **几乎不用改**，只需要把 Service 方法替换成 MyBatis-Plus 内置方法：

```java
@RestController
@RequestMapping("/api/products")
public class ProductController {

    private final ProductService productService;

    public ProductController(ProductService productService) {
        this.productService = productService;
    }

    @GetMapping
    public List<Product> list() {
        return productService.list();            // 查全部
    }

    @GetMapping("/{id}")
    public Product get(@PathVariable Long id) {
        return productService.getById(id);       // 查单个
    }

    @PostMapping
    public Product create(@RequestBody Product product) {
        productService.save(product);            // 新增（id 自动回填）
        return product;
    }

    @PutMapping("/{id}")
    public Product update(@PathVariable Long id, @RequestBody Product product) {
        product.setId(id);
        productService.updateById(product);      // 按 id 更新
        return product;
    }

    @DeleteMapping("/{id}")
    public void delete(@PathVariable Long id) {
        productService.removeById(id);           // 按 id 删除
    }
}
```

> 你发现了吗：Controller 代码变简单了，因为通用逻辑被 MyBatis-Plus 收走了。这就是框架的价值。

### 4. 配置自动填充（让 create_time/update_time 自动填）

新建配置类：

```java
package com.mall.mall.config;

import com.baomidou.mybatisplus.core.handlers.MetaObjectHandler;
import org.apache.ibatis.reflection.MetaObject;
import org.springframework.stereotype.Component;

import java.time.LocalDateTime;

@Component
public class MyMetaObjectHandler implements MetaObjectHandler {

    @Override
    public void insertFill(MetaObject metaObject) {
        this.strictInsertFill(metaObject, "createTime", LocalDateTime.class, LocalDateTime.now());
        this.strictInsertFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }

    @Override
    public void updateFill(MetaObject metaObject) {
        this.strictUpdateFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }
}
```

### 5. 扫描 Mapper（启动类加注解）

```java
@SpringBootApplication
@MapperScan("com.mall.mall.mapper")   // 扫描所有 Mapper 接口
public class MallApplication {
    public static void main(String[] args) {
        SpringApplication.run(MallApplication.class, args);
    }
}
```

## 五、进阶查询：条件构造器（Wrapper）

MyBatis-Plus 的 `QueryWrapper` 让你用链式调用拼查询条件，不用写 SQL：

```java
// 查价格 >= 1000 且库存 > 0 的商品，按价格降序
List<Product> list = productService.list(
    new QueryWrapper<Product>()
        .ge("price", 1000)
        .gt("stock", 0)
        .orderByDesc("price")
);
```

| 方法                               | 含义                         |
| -------------------------------- | -------------------------- |
| `eq("name", "手机")`               | 等于                         |
| `ne` / `gt` / `ge` / `lt` / `le` | 不等 / 大于 / 大于等于 / 小于 / 小于等于 |
| `like("name", "手")`              | 模糊匹配                       |
| `in("id", 1, 2, 3)`              | 在集合中                       |
| `orderByAsc` / `orderByDesc`     | 排序                         |

## 七、常见坑

| 问题                                      | 原因与解决                                                                 |
| --------------------------------------- | --------------------------------------------------------------------- |
| 启动报 `Access denied for user`            | 数据库用户名/密码错误，核对 application.yml                                        |
| 报 `Unknown database 'mall'`             | 没建库，先执行建库 SQL                                                         |
| 报 `Public Key Retrieval is not allowed` | URL 加 `&allowPublicKeyRetrieval=true`                                 |
| 时区报错                                    | URL 已加 `serverTimezone=Asia/Shanghai`                                 |
| 实体字段和表列名对不上                             | 列名是下划线（`create_time`），实体默认驼峰（`createTime`），MyBatis-Plus 默认开启驼峰映射，无需处理 |
| `create_time` 是 null                    | 没配 MetaObjectHandler 或没加 `@TableField(fill=...)`                      |
