# 商城后端服务 · 学习项目

> 从「前端开发」转型「Java 后端」的实战学习路线。目标是亲手搭出一个完整、可运行的商城后端服务。

## 一、项目定位

这是一个 **学习型项目**，目标不是一次性写出完美代码，而是沿着一条「由浅入深」的路线，逐步掌握 Java 后端开发的核心技能，最终交付一个结构清晰、可扩展、可运行的商城后端。

**最终交付物（商城后端服务）包含三大核心模块：**

| 模块 | 说明 |
| --- | --- |
| 店家管理 | 店家的注册、登录、信息维护、分页查询 |
| 货物管理 | 商品分类、商品增删改查、上下架、库存管理 |
| 订单管理 | 下单、订单状态流转、订单查询、取消订单 |

**支付部分仅做模拟**：提供模拟支付接口，不接入任何真实支付渠道，只演示「支付状态流转 + 订单联动」的完整链路。

## 五、给前端开发者的三点建议

1. **先建立「后端世界观」**：前端关心「界面如何渲染」，后端关心「数据从哪来、怎么校验、怎么存、怎么返回」。阶段一就是帮你完成这次思维切换。
2. **小步快跑，每阶段都跑通再前进**：每一阶段都配有「验收标准」，跑不通不要急着进入下一阶段。后端踩坑成本远高于前端，基础打牢最重要。
3. **代码跟着文档走，但不要只看不写**：所有代码示例都要亲手敲一遍，理解比复制更重要。遇到问题先看报错堆栈，这是后端开发最重要的能力。
