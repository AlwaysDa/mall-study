# 01 · 阶段 0：环境搭建

> 目标：把 Java 后端开发所需的环境一次性配好，并验证全部可用。
> 验收标准：终端能分别输出 `java -version`、`mvn -version`、`mysql --version` 的正确版本号。

## 零、版本选型：Spring Boot 和 JDK 怎么配？

> ⚠️ 重要更新（2026-09）：官方 Spring Initializr（start.spring.io）**已下架 3.x**，现在只能生成 **Spring Boot 4.x** 项目。这不影响学习，按下面的方案选即可。

先回答最常见的问题：**「页面上 Spring Boot 版本一堆，我该选哪个？」**

打开 <https://start.spring.io/> 的 Spring Boot 下拉框，你会看到：

| 页面选项 | 真实定位 | 结论 |
| --- | --- | --- |
| **4.0.8** | 4.x 最低的**正式发布版**（RELEASE） | ✅ **本课程选择** |
| 4.1.1 | 当前**默认版本**（最新稳定主线） | ✅ 也可以选 |
| 4.0.9 / 4.1.2 (SNAPSHOT) | 快照版，随时在变 | ❌ 不要选 |
| 4.2.0 (M1 / SNAPSHOT) | 里程碑 / 快照，未正式发布 | ❌ 不要选 |
| 3.x | **已下架**：3.x 开源支持期已结束，无法生成 | ❌ 不用纠结 |

**选择原则**：只选「正式发布版」，避开一切带 `SNAPSHOT` / `M1` / `M2` 字样的版本。学习项目追求稳定，`4.0.8` 或 `4.1.1` 都行，本课程以 **4.0.8** 为例。

**JDK 怎么配？** Spring Boot 4.x 官方支持 **Java 17 ~ 26**，最低仍是 17。所以：

| 组合 | 是否可行 | 说明 |
| --- | --- | --- |
| **JDK 17 + Spring Boot 4.0.8** | ✅ 最稳妥（本课程默认） | 官方支持范围内；Initializr 默认 Java 就是 17；Lombok / MyBatis-Plus 生态无需追新 |
| **JDK 21 + Spring Boot 4.1.x** | ✅ 推荐 | 更新的 LTS，语法更现代，Boot 4 官方鼓励用新 LTS |
| JDK 25 + Spring Boot 4.x | ⚠️ 能跑但不推荐 | 官方支持，但 Lombok（需 1.18.38+）、IDEA（需 2025.3+）等周边工具都要最新版，任何一个没跟上都会卡住进度 |

**为什么建议 17/21，而不是最新版 JDK 25？**

1. **学习重点不在 JDK 版本**：本路线要学的是分层架构、事务、状态机、鉴权这些通用能力，JDK 8 到 25 的日常写法几乎一样。追新版本对学习效果没有增益，只会增加配置风险。
2. **周边工具链**：JDK 25 下 Lombok、IDEA、部分第三方库必须用最新版才支持，任何一个没跟上都会卡住进度——对新手来说这是纯粹的负担。
3. **成熟度**：JDK 17/21 的兼容性验证最充分，网上教程与公司项目大量使用这两个组合，踩坑一搜就有答案。

**结论**：**Spring Boot 选 4.0.8（或 4.1.1），JDK 装 17**；想体验新语法可以装 **21**；JDK 25 等以后项目熟练了再升级也不迟，那时升级成本几乎为零。

## 一、需要安装的软件

| 软件 | 版本要求 | 作用 |
| --- | --- | --- |
| JDK | 17（推荐）或 21（LTS），搭配 Spring Boot 4.0.8 | Java 运行时与编译环境 |
| Maven | 3.9+ | 依赖管理与构建工具 |
| MySQL | 8.4 LTS（推荐） | 关系型数据库；版本选型见下节 |
| IDE | IntelliJ IDEA（推荐） | 开发环境 |
| 数据库客户端（可选） | DBeaver / Navicat | 可视化操作数据库 |
| 接口调试工具（可选） | Postman / Apifox | 调试 HTTP 接口 |

> 说明：Spring Boot 4.x 要求 Java 17 及以上（官方支持 17~26）。以下以 **JDK 17 + Spring Boot 4.0.8 + Windows** 为例，其他系统大同小异。

## 二、安装 JDK

1. 下载：推荐使用 [Adoptium Temurin](https://adoptium.net/) 的 JDK 17（免费、稳定）。
   - 也推荐国内镜像（如清华镜像）以加快下载速度。
2. 安装：一路下一步即可，**记住安装路径**（例如 `C:\Program Files\Eclipse Adoptium\jdk-17.x.x`）。
3. 配置环境变量：
   - 新增 `JAVA_HOME`，值为 JDK 安装路径。
   - 在 `Path` 中追加 `%JAVA_HOME%\bin`。
4. 验证：

```bash
java -version
# 期望输出类似：openjdk version "17.0.x"
```

## 三、安装 Maven

1. 下载 [Maven](https://maven.apache.org/download.cgi) 的 Binary zip 包，解压到如 `D:\dev\maven`。
2. 配置环境变量：
   - 新增 `MAVEN_HOME`，值为 Maven 解压路径。
   - 在 `Path` 中追加 `%MAVEN_HOME%\bin`。
3. **配置国内镜像（重要，否则下载依赖会很慢）**：编辑 `conf/settings.xml`，在 `<mirrors>` 中加入：

```xml
<mirror>
    <id>aliyunmaven</id>
    <mirrorOf>central</mirrorOf>
    <name>aliyun maven</name>
    <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

4. 验证：

```bash
mvn -version
# 期望输出 Maven 3.9.x 以及它使用的 Java 版本
```

## 四、安装 MySQL

### 0. 版本选型：下载页面那一堆版本选哪个？

MySQL 从 2026 年 7 月起启用了新的版本规则，下载页会出现 4 类版本，按如下选即可：

| 下载页版本 | 定位 | 本学习项目用不用 |
| --- | --- | --- |
| **8.4.11 LTS** | 8.4 长期支持版（推荐装这个） | ✅ **就选它** |
| 9.7.2 LTS | 更新的长期支持版 | ⚠️ 太新，教程少，没必要 |
| 26.7.0（Innovation） | 创新版（新特性尝鲜，季度更新） | ❌ 不适合，官方也注明别用于生产 |
| 8.0.46 | 8.0 系列收尾版，已停止维护（EOL） | ❌ 已过生命周期，别再开新项目用 |

**为什么选 8.4 LTS：**

1. **长期支持**：8.4 是 2024 年 4 月发布的 LTS，官方支持到 **2032 年**，每季度只出安全/稳定性补丁，装上后整个学习周期都不用操心升级。
2. **生态最匹配**：网上 99% 的教程、公司项目都是 8.x 语法，本教程所有建表 SQL 与用法和 8.4 完全一致，踩坑一搜就有答案。
3. **8.0 已 EOL 不要选**：8.0.46 是该系列的最后一个补丁，官方已停止维护，新项目起步就用停维护的版本是坏习惯。
4. **9.7 / 26.7 的新特性你用不到**：你的项目是店家/商品/订单 CRUD，用不上线程池、后量子加密这些新功能，追新只增加风险。

### 1. 下载与安装

1. 下载 [MySQL Community Server 8.4 LTS](https://dev.mysql.com/downloads/mysql/)（选 8.4.x LTS 下载页，Windows 选 MSI Installer）。
2. 安装时选择「Server only」即可，设置 root 用户密码，**务必记住这个密码**。
3. 配置：确保 MySQL 服务已启动（Windows 服务里找到 `MySQL84`，设为自动启动）。
4. 验证：

```bash
mysql -u root -p
# 输入密码后能进入 mysql> 命令行即成功
```

> 如果不想装客户端，可以直接用 IDE 或 DBeaver 连数据库，效果一样。

## 五、安装 IDE

推荐 **IntelliJ IDEA**（Community 版免费，已足够本课程使用；Ultimate 版对 Spring 支持更好，学生可申请免费授权）。

- 下载地址：<https://www.jetbrains.com/idea/download/>
- 安装后首次启动，可安装 `Lombok` 插件（新版本 IDEA 通常已内置）。

> 备选：VS Code + `Extension Pack for Java`，但对 Spring Boot 的支持不如 IDEA 顺畅，本课程默认使用 IDEA。

## 六、安装辅助工具（可选但推荐）

- **DBeaver**（免费）：可视化查看表结构、执行 SQL。下载：<https://dbeaver.io/>
- **Apifox / Postman**：调试接口。Apifox 对中文用户更友好，且支持生成接口文档。

## 七、一次性验证清单

全部通过即可进入阶段一：

```bash
java -version      # ✅ JDK 17+
mvn -version       # ✅ Maven 3.9+
mysql -u root -p   # ✅ 能登录 MySQL
```

在 IDEA 中新建一个普通 Java 项目，写一个 `main` 方法能跑出 `Hello`，说明 IDE 环境也正常。

## 八、常见问题

| 问题 | 解决 |
| --- | --- |
| `java` 命令找不到 | 检查 `JAVA_HOME` 和 `Path` 配置后，**重启终端** |
| Maven 下载依赖极慢 | 确认 `settings.xml` 镜像配置正确，并确认 IDEA 使用了该配置文件 |
| MySQL 忘记 root 密码 | 官方文档有「重置 root 密码」流程，或重装并记住密码 |
| 端口 3306 被占用 | `netstat -ano \| findstr 3306` 找到占用进程，或改 MySQL 端口 |
| IDEA 里 Maven 报错 | 在 `Settings → Build Tools → Maven` 里确认 Maven home 与 settings.xml 路径 |
